# ciberseguridad
PROYECTOS DE FUNDAMENTOS DE SEGURIDAD EN PLATAFORMAS COMPUTACIONALES

Portafolio de proyectos de ciberseguridad

Repositorio académico y profesional de Juan Carlos Fajardo Fernández, orientado a documentar prácticas de seguridad en plataformas computacionales, desarrollo seguro e integración de sistemas empresariales.

Aviso ético: todos los ejercicios fueron realizados en laboratorios propios, máquinas virtuales o entornos expresamente autorizados. Las direcciones IP, usuarios, dominios, credenciales y datos mostrados son ficticios o han sido anonimizados. Este repositorio no contiene secretos, información de clientes ni instrucciones destinadas al acceso no autorizado.

Sobre mí

Soy Java Backend Developer | Enterprise Integration Specialist, estudiante de Ingeniería en Informática y titular del Google Cybersecurity Professional Certificate. Mi experiencia combina desarrollo Java, servicios SOAP/REST, sistemas empresariales, automatización de pruebas y aplicación de controles básicos de ciberseguridad.

Me interesa especialmente la seguridad aplicada a:

APIs y microservicios.

Integraciones empresariales y sistemas legados.

Plataformas Linux y Windows Server.

Protección de datos y gestión de accesos.

Automatización de pruebas y documentación técnica.

Objetivo del repositorio

Este portafolio busca demostrar mi capacidad para:

Identificar riesgos y vulnerabilidades en entornos controlados.

Implementar controles preventivos, detectivos y correctivos.

Configurar plataformas siguiendo el principio de mínimo privilegio.

Documentar procedimientos, resultados y evidencias técnicas.

Comunicar hallazgos de manera clara para públicos técnicos y no técnicos.

Proteger la información sensible durante todo el ciclo de un proyecto.
